## Завдання

1. Створіть простий блог на Node.js з використанням Express. Реалізуйте
   фронтенд на React для відображення статей з блогу.

2. Додайте можливість додавання нових статей та коментарів. Реалізуйте
   систему категорій для статей.

3. Додайте можливість авторизації користувачів. Реалізуйте систему
   пошуку та фільтрації статей.

## Реалізовано

Express API для блогу.
React-фронтенд для відображення статей.
Додавання нових статей.
Додавання коментарів до статей.
Категорії статей.
Авторизація та реєстрація користувачів.
Пошук статей.
Фільтрація статей за категорією.
Збереження даних у `data/db.json`.

## Основні API-маршрути

`GET /api/articles` - отримати статті.
`GET /api/articles?search=react` - пошук статей.
`GET /api/articles?category=React` - фільтр за категорією.
`POST /api/articles` - додати статтю, потрібна авторизація.
`POST /api/articles/:id/comments` - додати коментар, потрібна авторизація.
`POST /api/register` - реєстрація.
`POST /api/login` - вхід.
`POST /api/logout` - вихід.
